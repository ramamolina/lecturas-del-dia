# Lecturas del Día

App para celular que muestra las lecturas de la misa de cada día y las deja listas para mandar por WhatsApp.

- Qué lecturas van cada día: Calendario litúrgico de la Conferencia Episcopal Argentina (Comisión Episcopal de Liturgia).
- Texto bíblico: *El Libro del Pueblo de Dios*, traducción argentina aprobada para la liturgia, tal como está publicada en vatican.va.

Uso privado y de prueba. Los derechos del texto bíblico pertenecen a sus editores.
